# Hospital Performance & Patient Analytics Dashboard
# Introduction
The Hospital Performance & Patient Analytics Dashboard is a data analytics project designed to analyze and visualize hospital operations and patient data through an interactive dashboard.
The project transforms raw healthcare data into meaningful insights, enabling better understanding of patient trends, operational efficiency, and financial performance.
# Problem Statement
Healthcare institutions generate large volumes of data, but extracting actionable insights from this data is complex and time-consuming.
This project addresses the problem by providing a centralized analytics solution that simplifies data interpretation through visualization.
# Objective
- The primary objective of this project is to:
- Analyze key hospital performance metrics
- Monitor patient admissions and readmission patterns
- Evaluate treatment cost and average length of stay
- Identify trends across departments and patient segments
- Develop an interactive dashboard for data-driven decision-making
# Solution Approach
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Feature understanding and segmentation
- Dashboard design using Power BI
- The final output is an interactive dashboard that enables users to explore hospital data efficiently.
# Dashboard Overview
- The dashboard provides insights into:
- Patient Metrics: Total admissions, total patients
- Operational Metrics: Bed occupancy, length of stay
- Clinical Metrics: Readmission rate, mortality rate
- Financial Metrics: Revenue and treatment cost
- Segmentation: Age group, gender, chronic conditions
- Department Analysis: Performance across departments
- Interactive filters allow users to drill down by hospital, department, doctor, insurance plan, gender, and age group.
# Filters

# Key Insights
- Higher readmission rates are observed in critical care departments
- Chronic diseases contribute significantly to hospital admissions
- Middle-aged patients represent the highest patient volume
- Revenue distribution varies across insurance types and hospitals
