# Hospital Analytics & Risk Monitoring System (Power BI Dashboard)

## Project Overview
This project is a comprehensive Hospital Analytics & Risk Monitoring Dashboard built using Power BI. It provides an executive-level overview of hospital performance, patient risk, financial metrics, and operational efficiency. The dashboard enables data-driven decision-making through interactive visualizations.

##  Problem Statement
Healthcare organizations generate large volumes of data across patients, treatments, billing, and operations. However, this data is often not effectively utilized for decision-making. Hospitals face challenges such as high readmission rates, inefficient resource utilization, increasing treatment costs, and difficulty in identifying high-risk patients.

The goal of this project is to transform raw healthcare data into actionable insights through an interactive dashboard that helps stakeholders monitor performance, reduce risks, and improve overall hospital efficiency.

## Approach
The solution follows a structured data analytics approach:

- Data was collected from multiple sources such as patients, admissions, treatments, billing, and hospitals  
- Data cleaning and preprocessing were performed to handle missing values and ensure consistency  
- A proper data model (star schema) was designed to establish relationships between tables  
- DAX measures were created to calculate KPIs like readmission rate, mortality rate, and average length of stay  
- Interactive dashboards were built in Power BI with filters and drill-through capabilities  
- Visualizations were designed to highlight trends, risks, and performance metrics  

## Objectives
- Monitor hospital performance in real-time  
- Analyze patient admissions and readmission trends  
- Track financial performance and treatment costs  
- Identify high-risk patients and chronic conditions  
- Improve operational efficiency  

## Tools & Technologies
- Power BI  
- SQL  
- Data Modeling (Star Schema)  
- DAX  

## Dashboard Features
- Executive Overview (Admissions, Patients, LOS, Mortality, etc.)  
- Patient Risk Analytics (Chronic conditions, risk segmentation)  
- Financial Analysis (Revenue, treatment cost)  
- Time Series Analysis (Monthly trends)  
- Hospital Operations (Department performance, bed occupancy)  
- Drill-through filters (Branch, Doctor, Age, Gender, Insurance)

- Optimize resource allocation in departments with high bed occupancy rates  
- Implement preventive care programs for high-risk patients (e.g., diabetes, hypertension)  
- Control treatment costs by analyzing high-expense procedures and optimizing workflows  
- Improve hospital performance by benchmarking across branches and departments  
- Use data-driven insights to enhance patient satisfaction and operational efficiency
