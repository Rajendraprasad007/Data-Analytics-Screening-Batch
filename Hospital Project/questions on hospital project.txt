## 🔹 Technical (SQL / Python / Data Cleaning)

   **A:** Use `patient_id` and `admission_id` as keys, validate against master tables.  

3. **Q:** How do you calculate hospital revenue?  
   **A:** `SUM(billing_amount)` grouped by department/doctor.  

4. **Q:** How do you detect missing values in Pandas?  
   **A:** `df.isnull().sum()` + group‑wise imputation strategies.
