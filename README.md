# Hospital Operations & Patient Risk Intelligence Dashboard
Project Description

This project is a Power BI dashboard designed to provide a complete view of hospital operations and patient analytics. It acts as a decision-support system for hospital management, helping them monitor performance, identify risks, and improve operational efficiency.

The dashboard integrates multiple datasets such as patients, admissions, billing, treatments, and hospital branches to deliver meaningful insights through interactive visualizations.

# Objective
The main goal of this project is to:

Analyze patient volume and admission trends
Monitor readmission and mortality rates
Evaluate hospital branch performance
Understand disease patterns and patient demographics
Track financial performance and revenue distribution
# Key Features
KPI Cards for:

Total Patients
Total Admissions
Readmission Rate
Average Treatment Cost
Mortality Rate
Bed Occupancy

# Interactive Visualizations:
Monthly Admissions Trend
Readmission Rate by Department
Top Diseases Analysis
Revenue by Hospital Branch
Age Group & Gender Analysis
Insurance Type Distribution

# Advanced Features:
Slicers for dynamic filtering (Branch, Department, Date, etc.)
Drill-through for patient-level analysis

Tooltips for detailed insights
Clean and professional UI design
# Tools & Technologies Used
Power BI
Power Query (Data Cleaning & Transformation)
DAX (Data Analysis Expressions)
Data Modeling (Star Schema)
